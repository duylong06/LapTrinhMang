# Kết quả đo đạc

Số liệu thô của các thí nghiệm E1–E6, dạng CSV. Cách đo và định dạng: [docs/07-ke-hoach-do-dac.md](../docs/07-ke-hoach-do-dac.md).

| File | Thí nghiệm | Nhiệm vụ |
|---|---|---|
| `e1-kich-thuoc-khoi.csv` | Kích thước khối và tốc độ | T38 |
| `e2-moi-truong.csv` | Localhost, cáp, WiFi 2,4 GHz, WiFi 5 GHz | T39 |
| `e3-so-sanh.csv` | So với Zalo, Google Drive, USB | T39 |
| `e4-truyen-tiep.csv` | Truyền tiếp khi đứt ở 25/50/75% | T39 |
| `e5-udp-thuan.csv` | Gửi file bằng UDP thuần | T36 |
| `e6-do-tim.csv` | Thời gian xuất hiện, biến mất | T39 |

Mỗi file bắt đầu bằng các dòng chú thích `#` ghi môi trường đo. Không sửa tay số liệu đã đo; đo lại thì thêm dòng mới và ghi chú lý do.
